# 任务 (Task)
（重要声明：本任务为纯文本离线数据阅读与 JSON 格式化输出，所有商品文本数据均已在消息末尾完整给出，无需联网、无需访问任何外部网站或执行外部程序，请仅根据给定文本直接输出纯文本 JSON。）
请根据末尾 `<comparison_input>` 标签内提供的【我方候选标品信息（含已算好的各个 `unit` 的性价比值）】与【已拉取完整详情、多规格 SKU 价格及运费的闲鱼同款候选商品列表 (`xianyu_detailed_items`)】，进行严格的终审复核与含邮总价核算，从中选出**真实性价比最高的 1 个闲鱼同款商品**，计算其对应 `unit` 的性价比值并给出最终胜负判断。

---

## 一、 核心终审比价与计算铁律

### 1. 基于完整详情 (`detail_verified_info`) 的终审复核与淘汰规则
每个进入本阶段的闲鱼商品均已通过详情页接口拉取了 `detail_verified_info`，包含：
- `desc`：商品完整正文描述；
- `transport_fee`：明确运费金额（元），以及 `is_free_shipping`（是否包邮，`transport_fee == 0` 为包邮）；
- `has_multi_sku` 与 `sku_list`：多规格列表，每个 SKU 包含 `spec_text`（具体规格名称）、`price`（该规格真实售价）、`quantity`（该规格剩余库存数量）；
- `cpv_labels`：闲鱼商品结构化属性标签（如品牌、型号、规格参数）。

**在比价前，必须逐一核查并剔除以下不合格商品（不放入最终 `comparable_item_ids`）**：
1. **非同款 / 非全新 / 已过期 / 站外引流**：
   - 若详情正文 `desc`、`cpv_labels` 或 `sku_list` 暴露出该商品与我方商品**并非同品牌同款/同系列**（例如我方是 240mm 日用卫生巾，详情里只有安睡裤或护垫；或品牌不一致），必须剔除；
   - 若正文表明是**二手拆封/用过闲置**、**空瓶/配件**、**仅限同城自提不发快递**，或**已过期/临期瑕疵品**（注意当前年份为 **2026 年**，若保质期截止日期早于当前时间则已过期），必须剔除；
   - 若正文包含明显的**站外淘客/拼多多引流话术**（如“拍前私聊改价”、“去淘宝/拼多多拍单”、“复制口令领券”且并非真实闲鱼直卖），必须剔除。
2. **缺少具体规格情况或缺少明确邮费信息（一票否决）**：
   - **规格必须明确可比**：如果一个闲鱼商品在标题、正文 `desc`、`sku_list` 和 `cpv_labels` 中**完全没有写明具体规格数量**（例如不知道是多少克/毫升/多少包/多少抽/多少片，无法与我方进行同维度对比），**必须剔除**！
   - **严禁跨量级模糊容器对比**：如果我方是正装（如 `500g` 面霜或 `500ml` 洗发水），而闲鱼是旅行装小样（如 `60ml`），**绝对禁止按 `"1瓶 vs 1瓶"` 或 `"1支 vs 1支"` 这种模糊容器单位直接对比**！必须换算为精确的 `g` 或 `ml` 对比；若某一方只写了“1瓶/1支”且完全无法获知其真实克重/毫升数，导致无法排除小样与正装错配风险时，必须判定为不可比并剔除！
   - **真实售价与邮费必须清晰**：如果外显标价明显为虚假引流价（如 `0.01` 元、`1.0` 元），且 `sku_list` 与正文 `desc` 中均未给出真实售卖价格，或者正文写明“邮费自理/按距离算邮费”但 `transport_fee` 未体现且无法得知具体运费金額，**必须剔除**！

---

### 2. 真实可比含邮总价 (`真实可比总价`) 与对应规格核算规则
对于通过上述复核的每一个可比闲鱼商品，必须按以下规则确定其**真实可比含邮总价**与**对应规格数量**：
1. **多规格商品 (`has_multi_sku == true` 且 `sku_list` 非空)**：
   - **只看有库存的同款规格**：必须筛选 `sku_list` 中 `quantity > 0`（在售有货）且 `spec_text` 属于我方同款商品的 SKU（剔除无货 SKU `quantity <= 0`，剔除配件/工具/其他款式的低价引流 SKU）；
   - 若所有同款 SKU 的库存 `quantity` 均为 `0`，则该商品无货不可买，必须剔除；
   - 对每个有效在售同款 SKU，其**真实可比含邮总价 = `sku.price + transport_fee`**，对应数量为该 `sku.spec_text` 所标明的总数量（严禁拿最低引流 SKU 的价格去搭配最大包装 SKU 的数量！）。
2. **单规格商品 (`has_multi_sku == false` 或 `sku_list` 为空)**：
   - 核对详情售价 `price` 与正文 `desc`：
     - 若正文 `desc` 中明确规定了打包售卖规则（例如外显 `3.9` 元但正文写明 `“十包38.8元包邮，单包不发”` 或 `“19.9元20包包邮”`），必须以正文规定的**真实成交总价**和**对应总数量**为准；
     - 若正文写明 `“单件不包邮，满X件包邮”`，则要么按满包邮门槛的件数计算总价与总数量，要么在单件价格上加上运费，**绝不能将不包邮的裸价直接当作包邮价**！
     - 常规单规格商品的**真实可比含邮总价 = `price + transport_fee`**。

---

### 3. 选出闲鱼中性价比最高的 1 个商品 (`best_xianyu_item_id`)
- 遍历所有通过复核的可比闲鱼商品（及其有效在售 SKU），逐一核算其单位性价比：
  `每1元能买到的数量 = 该单位总数量 / 真实可比含邮总价`
- 选出所有可比闲鱼商品中**单位性价比最高（即每 1 元能买到的同款数量最多、折合含邮单价最便宜）**的那 **1 个**商品作为 `best_xianyu_item_id`。
- **防遗漏铁律**：严禁漏看列表中折算单价更低的同款商品或更划算的大包装 SKU。
- `best_xianyu_item_id` **必须严格来自输入列表 `xianyu_detailed_items` 中的 `item_id` 原值，严禁编造或修改**。
- `best_xianyu_price` 必须填入该最佳商品（及所选最佳 SKU）的**真实可比含邮总价（含运费 `transport_fee`）**。
- `best_xianyu_spec` 必须清晰写明该最佳商品的**具体规格、SKU 售价与运费构成**（例如：`"百适柔4层抽纸整箱30包（360张/包），SKU售价10.0元 + 运费0.0元(包邮) = 10.0元"`）。

---

### 4. 计算匹配的各个 `unit` 的性价比值 (`xianyu_unit_cost_performance`)
- 我方候选标品在 `my_candidate_product.unit_cost_performance` 中已给出了各个 `unit` 的性价比值，计算公式为：
  `unit_cost_performance[unit] = round(unit_quantities[unit] / price, 6)`
  （代表**每 1 元人民币能买到的该 `unit` 数量**，数值越大代表性价比越高）。
- 请将选出的最佳闲鱼商品的规格换算为与我方 `my_candidate_product.unit_cost_performance` **相同的 `unit`**（支持标准物理换算：`1kg = 2斤 = 1000g`，`1L = 1000ml`）：
  - 优先对齐精确的物理/计数单位（如 `g`、`ml`、`片`、`抽`、`张`、`粒`、`只`、`包`）；
  - 仅提取闲鱼商品标题、`desc`、`sku_list` 或 `cpv_labels` 中有明确依据的 `unit`（例如闲鱼明确写了 `30包` 但未写总张数，则提取 `"包": 30.0`，不要凭空猜测张数；若写明了 `300张/包，共30包`，则可同时提取 `"包": 30.0, "张": 9000.0`）；
  - 将换算后的数量填入 `xianyu_unit_quantities`；
  - 按完全相同的公式 `round(xianyu_unit_quantities[unit] / best_xianyu_price, 6)` 计算出 `xianyu_unit_cost_performance`。

---

### 5. 返回大模型判断字段 (`llm_winner` 与 `llm_reason`)
- 给出你的最终性价比胜负判断 `llm_winner`：
  - `"my_product"`：我方候选标品的性价比高于闲鱼最佳可比商品；
  - `"xianyu_product"`：闲鱼最佳可比商品的性价比高于我方候选标品；
  - `"tie"`：双方性价比完全持平；
  - `"no_comparable"`：复核详情、规格与邮费后，没有任何一个闲鱼商品符合同款可比要求（此时 `has_comparable_item` 设为 `false`，`comparable_item_ids` 设为 `[]`，`best_xianyu_item_id` 设为 `""`）。
