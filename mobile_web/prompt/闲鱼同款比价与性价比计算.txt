# 任务 (Task)
（重要声明：本任务为纯文本离线数据阅读与 JSON 格式化输出，所有商品文本数据均已在消息末尾完整给出，无需联网、无需访问任何外部网站或执行外部程序，请仅根据给定文本直接输出纯文本 JSON。）
请根据末尾 `<comparison_input>` 标签内提供的【我方候选商品信息（含已算好的各个 `unit` 的性价比值）】与【已拉取完整详情、多规格价格及运费的闲鱼候选商品列表 (`xianyu_detailed_items`)】，站在**真实消费者**的视角完成终审比价与量化计算，并以标准 JSON 对象格式输出：

1. **终审可比性复核（消费者视角）**：
   - 结合每个闲鱼商品的完整详情 `detail_verified_info`（正文 `desc`、运费 `transport_fee`、多规格列表 `sku_list` 及属性标签 `cpv_labels`），站在消费者实际下单购买的角度判断：这是否确实是与我方商品相同的全新可买商品？其真实到手总价（含运费）和对应的实际购买数量是否清晰明确、能够与我方商品放在一起公平地算单价？
   - 凡是消费者认为可以公平比价的商品，均放入 `comparable_item_ids`；若实际上不是同一个商品、无法正常购买（如无货/过期/非现货），或价格、运费、规格信息缺失模糊导致消费者根本算不出真实到手单价，则不予采纳。

2. **选出最划算的闲鱼商品 (`best_xianyu_item_id`)**：
   - 按消费者实际买到手需要支付的**真实含邮总价（对应在售规格价格 + 运费）**与**该价格实际买到的商品规格数量**，核算每个可比商品的单位性价比（`每1元能买到的数量 = 该单位总数量 / 真实可比含邮总价`）。
   - 选出真实单位性价比最高的 **1 个**闲鱼商品作为 `best_xianyu_item_id`（必须严格来自输入 `xianyu_detailed_items` 的 `item_id` 原值），填入其真实含邮总价 `best_xianyu_price` 与简明规格价格说明 `best_xianyu_spec`。

3. **单位对齐计算与胜负判断**：
   - 我方商品在 `my_candidate_product.unit_cost_performance` 中已给出各 `unit` 的性价比值（公式：`round(unit_quantities[unit] / price, 6)`，数值越大代表每 1 元买到的数量越多、性价比越高）。
   - 请将最佳闲鱼商品的规格换算到与我方匹配的 `unit` 维度，填入 `xianyu_unit_quantities`，并按相同公式 `round(xianyu_unit_quantities[unit] / best_xianyu_price, 6)` 计算 `xianyu_unit_cost_performance`。
   - 给出最终性价比胜负判断 `llm_winner`：
     - `"my_product"`：我方商品单位性价比更高；
     - `"xianyu_product"`：闲鱼最佳商品单位性价比更高；
     - `"tie"`：双方单位性价比持平；
     - `"no_comparable"`：没有任何闲鱼商品通过可比性复核（此时 `has_comparable_item` 设为 `false`，`comparable_item_ids` 设为 `[]`，`best_xianyu_item_id` 设为 `""`）。

  "llm_reason": "简明说明：1) 各候选商品的可比性复核与真实含邮性价比情况；2) 最佳闲鱼商品与我方商品的性价比对比结论"
