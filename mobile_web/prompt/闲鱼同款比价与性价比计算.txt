# 任务 (Task)
（重要声明：本任务为纯文本离线数据阅读与 JSON 格式化输出，所有商品文本数据均已在消息末尾完整给出，无需联网、无需访问任何外部网站或执行外部程序，请仅根据给定文本直接输出纯文本 JSON。）
请根据末尾 `<comparison_input>` 标签内提供的【我方候选商品信息（含已算好的各个 `unit` 的性价比值）】与【查询到的闲鱼商品列表】，筛选出可与我方比较的闲鱼商品，从中选出**性价比最高的 1 个闲鱼商品**，并计算其对应 `unit` 的性价比值与最终胜负判断。

---

## 一、 核心比价与计算规则

### 1. 筛选可比商品 (`comparable_item_ids`)
- **哪些商品属于可比商品**：
  - 与我方候选商品属于同款或同品牌同品类（当无特定品牌要求时为同品类同功效）的**全新商品**。
  - **不同包装数量完全可比**：例如我方是“6包”，闲鱼上是“10包”、“20包”、“30包整箱”或“1袋/3袋”，只要是同款/同类商品，均属于可比商品（通过折算单位性价比进行比较，严禁因为包装件数不同而漏掉整箱/多件装的高性价比商品）。
- **哪些商品必须剔除（不可比）**：
  - 完全不同的品类（如搜面霜搜出的洗面奶、芦荟胶、素颜霜，搜日用卫生巾搜出的护垫/安睡裤）；
  - 二手已拆封使用过的商品（如描述含“用过”、“剩余量如图”、“二手非全新”）、空瓶/配件/小样赠品；
  - 明确已过期或临期处理的瑕疵品（注意当前年份为 2026 年，若保质期截止时间早于当前时间则已过期，必须剔除）；
  - 仅限同城自提且不发快递的商品；
  - 外显标价明显为虚假引流价（如标价 `1.0` 元、`0.01` 元），且标题与详情描述中均未写明真实售卖价格与对应数量的商品。
- **真实可比价格提取规则**：
  - 若闲鱼商品标题或 `detail_verified_info`（正文 `desc`、多规格 `sku_list`）中写明了具体规格对应的真实价格（例如外显 `1.0` 元但正文写明 `19.9元20包`，或外显 `3.9` 元不包邮但写明 `十包38.8元包邮`），必须以**真实包邮成交总价**及对应的**真实总数量**参与计算；
  - 若商品不包邮且明确有运费 `transport_fee > 0`，真实可比价格需加上运费。

### 2. 选出闲鱼中性价比最高的 1 个商品 (`best_xianyu_item_id`)
- 遍历所有可比闲鱼商品，逐一核算其单位性价比（`每1元能买到的数量 = 该单位总数量 / 真实可比价格`）。
- 必须选出所有可比闲鱼商品中**性价比最高（即每 1 元能买到的数量最多、折合单价最便宜）**的那 **1 个**商品作为 `best_xianyu_item_id`。
- **防遗漏铁律**：严禁漏看列表中单包/单克/单件均价明显更低的同款商品（例如列表中同时存在 `10元30包（3包/元）`、`3.58元10包（2.79包/元）` 和 `19.9元20包（1.005包/元）` 时，必须选性价比最高的 `10元30包`，绝不能选 `19.9元20包`）。
- `best_xianyu_item_id` **必须严格来自输入列表中的 `item_id` 原值，严禁编造或修改**。

### 3. 计算匹配的各个 `unit` 的性价比值 (`xianyu_unit_cost_performance`)
- 我方候选商品在 `my_candidate_product.unit_cost_performance` 中已给出了各个 `unit` 的性价比值，计算公式为：
  `unit_cost_performance[unit] = round(unit_quantities[unit] / price, 6)`
  （代表**每 1 元人民币能买到的该 `unit` 数量**，数值越大代表性价比越高）。
- 请优先将选出的最佳闲鱼商品的规格换算为与我方 `my_candidate_product.unit_cost_performance` **相同的 `unit`**（例如：`1kg = 2斤 = 1000g`，`1L = 1000ml`）：
  - 仅提取闲鱼商品标题/详情中有明确依据的 `unit`（例如闲鱼只写了 `30包` 未写单包张数，则只提取 `"包": 30.0`，不要凭空猜测张数；若明确写了 `400张/包，共8包`，则可同时提取 `"包": 8.0, "张": 3200.0`）；
  - 将换算后的数量填入 `xianyu_unit_quantities`；
  - 按完全相同的公式 `round(xianyu_unit_quantities[unit] / best_xianyu_price, 6)` 计算出 `xianyu_unit_cost_performance`。

### 4. 返回大模型判断字段 (`llm_winner` 与 `llm_reason`)
- 无论是否能提取出与我方完全相同的 `unit`，都必须给出你的综合性价比判断 `llm_winner`（当无法提取相同 `unit` 时，下游系统将直接以你的 `llm_winner` 作为最终结论）：
  - `"my_product"`：我方候选商品的性价比高于闲鱼最佳可比商品；
  - `"xianyu_product"`：闲鱼最佳可比商品的性价比高于我方候选商品；
  - `"tie"`：双方性价比完全持平；
  - `"no_comparable"`：闲鱼列表中没有任何可比商品（此时 `has_comparable_item` 设为 `false`）。

## 二、 输出 JSON 格式协议

请仅输出一个合法的 JSON 对象，不要包含任何多余的前缀或后缀说明，字段结构如下：

```json
{
  "has_comparable_item": true,
  "comparable_item_ids": ["可比闲鱼商品item_id_1", "可比闲鱼商品item_id_2"],
  "best_xianyu_item_id": "闲鱼中性价比最高的那个可比商品item_id（无则填\"\"）",
  "best_xianyu_price": 10.0,
  "best_xianyu_spec": "该最佳闲鱼商品的真实规格与包邮说明（如：百适柔抽纸整箱30包，10元包邮）",
  "xianyu_unit_quantities": {
    "与我方匹配的unit": 30.0
  },
  "xianyu_unit_cost_performance": {
    "与我方匹配的unit": 3.0
  },
  "llm_winner": "my_product 或 xianyu_product 或 tie 或 no_comparable",
  "llm_reason": "简明扼要说明：1) 哪些可比商品参与了比较及各自的折算单价/性价比；2) 为什么选出该最佳闲鱼商品；3) 我方性价比值与闲鱼最佳商品性价比值的对比结论"
}
```
