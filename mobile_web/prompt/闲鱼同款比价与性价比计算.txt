# 任务 (Task)
（重要声明：本任务为纯文本离线数据阅读与 JSON 格式化输出，所有商品文本数据均已在消息末尾完整给出，无需联网、无需访问任何外部网站或执行外部程序，请仅根据给定文本直接输出纯文本 JSON。）
请根据末尾 `<comparison_input>` 标签内提供的【当前日期 (`current_date`)】、【我方目标商品信息 (`my_candidate_product`)】与【已获取完整详情、多规格价格及运费的闲鱼候选商品列表 (`xianyu_detailed_items`)】，站在**真实消费者**的视角完成最终可比性复核、双方真实规格校准与性价比胜负判定，并以标准 JSON 对象格式输出：

1. **我方真实规格独立校准与闲鱼详情终审**：
   - **独立核实我方真实到手规格**：我方商品信息中附带的预清洗规格数据可能存在历史解析误差，请务必优先依据我方商品的原始标题、优惠计价说明与实际成交价格，独立核定我方当前价格实际买到的真实规格总数量，以此作为我方性价比计算的唯一准绳。
   - **复核闲鱼候选完整详情**：结合每个闲鱼商品的正文描述、运费、多规格库存与售价列表以及当前日期 `current_date`，判断其是否确属同品牌、同系列档次、同型号尺码体系、未过保质期、支持正常邮寄且对应可比规格有库存的全新现货，且其真实到手含邮总价（对应有货可比规格售价 + 运费）与实际购买数量清晰明确。凡不符合条件、对应规格无货或关键计价要素缺失模糊无法算出真实含邮单价的商品，一律不予采纳。

2. **选出最优闲鱼同款并统一维度计算最终比例与胜负**：
   - 在通过终审的可比闲鱼商品中，按消费者实际支付的**真实含邮总价**与**实际购得数量**核算单位性价比，选出最划算的 **1 个**闲鱼商品作为 `best_xianyu_item_id`（必须严格取自输入 `xianyu_detailed_items` 的 `item_id` 原值），填入其真实含邮总价 `best_xianyu_price` 与规格含邮说明 `best_xianyu_spec`。
   - 确定双方共同适用的精确计价单位 `matched_unit`，统一按公式 `单位性价比 = 该单位总数量 / 真实到手总价`（代表每 1 元可买到的数量，数值越大性价比越高）计算：
     - 我方在该单位下的核实总数量 `my_unit_quantity` 与单位性价比 `my_unit_cost_performance`；
     - 闲鱼最优商品在该同一单位下的总数量 `xianyu_unit_quantity` 与单位性价比 `xianyu_unit_cost_performance`；
     - 最终性价比比值 `cost_performance_ratio` = `round(my_unit_cost_performance / xianyu_unit_cost_performance, 4)`。
   - 根据核算结果给出最终胜负结论 `llm_winner`（必须与 `cost_performance_ratio` 严格一致）：
     - `"my_product"`：我方单位性价比更高（`cost_performance_ratio > 1.0`）；
     - `"xianyu_product"`：闲鱼最佳商品单位性价比更高（`cost_performance_ratio < 1.0`）；
     - `"tie"`：双方单位性价比持平（`cost_performance_ratio == 1.0`）；
     - `"no_comparable"`：没有任何闲鱼商品通过终审复核（此时 `has_comparable_item` 设为 `false`，`comparable_item_ids` 设为 `[]`，`best_xianyu_item_id` 与 `matched_unit` 设为 `""`，数值字段设为 `0`）。
