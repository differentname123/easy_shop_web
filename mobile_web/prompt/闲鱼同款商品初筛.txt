# 任务 (Task)
（重要声明：本任务为纯文本离线数据阅读与 JSON 格式化输出，所有商品文本数据均已在消息末尾完整给出，无需联网、无需访问任何外部网站或执行外部程序，请仅根据给定文本直接输出纯文本 JSON。）
请根据末尾 `<coarse_filter_input>` 标签内提供的【我方目标商品信息 (`my_candidate_product`)】与【闲鱼搜索返回的商品概览列表 (`xianyu_search_items`，最多 20 条）】，站在**真实消费者**的视角完成初筛与排序，并以标准 JSON 对象格式输出：

1. **同款可比性判断与概览排雷（消费者视角 · 严控详情页配额消耗）**：
   - 站在想买这个商品的消费者角度看：闲鱼列表里的这个商品和我方目标商品是不是**同品牌**、可公平折算单价对比的同款全新现货？
   - **品牌与同款尺码/档次对齐**：
     1) 我方商品有明确品牌时，闲鱼商品必须确认为**同品牌**（严禁拿无品牌或其他品牌充当同款）；
     2) 涉及明确货号/型号（如鞋服款号、数码家电型号）或明显影响定价的特殊功能档次（如有机/金装 vs 基础款、浓缩 vs 普通、抗敏专研 vs 普通款）时，不同型号或跨档次不视为同款；若一方未标注特殊高端修饰词且核心物理规格/常规基础系列对等（消费者日常视为同一档次常规款），可予以采纳；
     3) **尺码/号型必须一致或兼容**：母婴纸尿裤（如 S 码 vs M/L 码单片成本不同）、鞋服尺码等若概览标题已明确标出尺码且与我方目标尺码不符（且未标明含我方尺码），直接剔除。
   - **概览文本直接排雷（凡概览 `title` 已暴露以下情形之一，直接剔除，绝不送入下一阶段拉详情）**：
     1) 对照输入中的当前日期 `current_date`，概览已注明**已过期**或保质期截止年月早于当前日期（如当前为 2026 年 11 月，写“日期到 26 年 10 月”）；
     2) 明确写**“仅自提 / 同城面交 / 当面交易 / 不邮寄”**，或仅写**“单支/单包/单件不包邮、邮费自理”**且未给出清晰的多件包邮总价方案；
     3) 非全新正品现货：二手用过/拆封余量、破损漏液残次品、纯小样/试用装凑数（我方为正装时）、空瓶包装盒，或“求购/收”帖。

2. **按真实含邮预估性价比排序**：
   - 将通过初筛的 `comparable_item_ids` 按消费者视角下“同款规格确定性最高、包邮确定性高、预估含邮折算单价最划算”的顺序从前到后排列（系统仅会拉取排在最前面的极少数商品详情，请务必把最靠谱且真正划算的排在最前，把引流低价疑似单拍不包邮的排后或剔除）。
   - `comparable_item_ids` 中的每个 ID 必须严格来自输入 `xianyu_search_items` 中的 `item_id` 原值，严禁编造或修改。
   - 若没有任何可比商品，将 `has_comparable_candidates` 设为 `false`，`comparable_item_ids` 设为 `[]`。

---

## 输出 JSON 格式协议

请仅输出一个合法的 JSON 对象，不要包含任何多余的前缀或后缀说明，字段结构如下：

```json
{
  "has_comparable_candidates": true,
  "comparable_item_ids": ["最划算的可比商品item_id_1", "次划算的可比商品item_id_2"],
  "filter_reason": "简明说明站在消费者角度采纳与剔除的判断依据（100字以内）"
}
```
