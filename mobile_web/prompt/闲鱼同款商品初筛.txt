# 任务 (Task)
（重要声明：本任务为纯文本离线数据阅读与 JSON 格式化输出，所有商品文本数据均已在消息末尾完整给出，无需联网、无需访问任何外部网站或执行外部程序，请仅根据给定文本直接输出纯文本 JSON。）
请根据末尾 `<coarse_filter_input>` 标签内提供的【我方目标标品信息 (`my_candidate_product`)】与【闲鱼搜索返回的初筛商品概览列表 (`xianyu_search_items`，最多 20 条）】，筛选出所有**与我方商品属于「同款商品」且具备可比性**的闲鱼商品 `item_id`，供下一阶段逐个拉取完整商品详情、多规格 SKU 价格与真实运费。

---

## 一、 核心同款筛选规则

### 1. 什么是「同款可比商品」（必须同时满足以下条件才可放入 `comparable_item_ids`）
1. **必须同品牌、同款/同系列、同细分子类**：
   - **品牌严格对齐**：若我方目标商品具有明确品牌（查看 `brand` 字段或 `name` 标题中的品牌名，如“高洁丝”、“百适柔”、“漫花”、“蓝月亮”、“超能”、“仙蒂奈儿”等），闲鱼商品**必须是同一品牌**的商品！**严禁**把其他品牌的同类商品（例如我方是高洁丝，闲鱼是七度空间/苏菲/护舒宝；或者我方是特定品牌，闲鱼是完全无关的B品牌）当作可比商品！
   - **仅当无特定品牌限制的功能标品**：仅当我方商品本身确实为无特定大牌约束的通用成分/标准件标品，且闲鱼商品在核心成分、功效、款式形态上与我方完全一致时，才允许同款对齐。
   - **细分子类与核心属性严格对齐**：
     - 严禁跨子类混比！例如：
       - 我方是「日用卫生巾（如 240mm）」，闲鱼上的「安睡裤」、「护垫」、「夜用加长 420mm」**均不属于同款**，必须剔除；
       - 我方是「面霜」，闲鱼上的「洗面奶」、「身体乳」、「芦荟胶」、「眼霜」**均不属于同款**，必须剔除；
       - 我方是「抽纸」，闲鱼上的「卷纸」、「湿巾」、「厨房吸油纸」**均不属于同款**，必须剔除；
       - 我方是「洗衣液」，闲鱼上的「洗衣粉」、「洗衣凝珠」、「柔顺剂」**均不属于同款**，必须剔除。

2. **必须是全新正品实物**：
   - 剔除标题中明确标注为“二手”、“已拆封”、“用过”、“余量如图”、“闲置转让非全新”的商品；
   - 剔除空瓶、包装盒、替换装配件（除非我方本身就是替换装）、小样赠品（当与正装明显不可比时）、过期或临期瑕疵处理品；
   - 剔除“仅限同城自提/当面交易不邮寄”的商品；
   - 剔除明显的淘客/拼多多站外引流贴（如标题写“去淘宝拍”、“发链接领券”）。

3. **初筛阶段的包容性原则（关于包装件数、多规格与运费）**：
   - **不同包装数量完全可比**：只要确认是**同品牌同款全新商品**，无论闲鱼标题写的是“单件/单包”、“6包”、“10包”、“20包”还是“整箱30包”，**全部应当选入 `comparable_item_ids`**（下一阶段会通过折算单位性价比进行公平比较）。
   - **外显价格疑似多规格引流价的同款商品应当保留**：由于闲鱼列表页只展示默认或最低 SKU 的外显价格 `display_price` 及列表是否包邮，很多正经卖同款多规格的卖家会在详情页的 `sku_list` 或正文 `desc` 中写明各规格真实售价与运费。因此，在当前初筛阶段，**只要标题表明它是同品牌同款全新商品，即使外显价格偏低或不包邮，也应选入 `comparable_item_ids`**，交由下一阶段拉取详情 (`get_xianyu_item_detail`) 后再做精确价格与邮费核验。

4. **ID 真实性铁律**：
   - `comparable_item_ids` 中的每一个 ID **必须严格来自输入 `xianyu_search_items` 中的 `item_id` 原值，严禁编造或修改**。
   - 请按照与我方商品的**同款匹配度从高到低**排序输出 `comparable_item_ids`。
   - 如果 20 条搜索结果中没有任何一条属于同款可比商品，请将 `has_comparable_candidates` 设为 `false`，`comparable_item_ids` 设为 `[]`。

请仅输出一个合法的 JSON 对象，不要包含任何多余的前缀或后缀说明，字段结构如下：

```json
{
  "has_comparable_candidates": true,
  "comparable_item_ids": ["同款可比闲鱼商品item_id_1", "同款可比闲鱼商品item_id_2"],
  "filter_reason": "简明说明：1) 选出的商品为什么判定为同品牌同款；2) 被剔除的商品主要是因为不同品牌、不同子类还是二手/引流（100字以内）"
}
```
