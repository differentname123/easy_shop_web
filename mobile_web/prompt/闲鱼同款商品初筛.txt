# 任务 (Task)
（重要声明：本任务为纯文本离线数据阅读与 JSON 格式化输出，所有商品文本数据均已在消息末尾完整给出，无需联网、无需访问任何外部网站或执行外部程序，请仅根据给定文本直接输出纯文本 JSON。）
请根据末尾 `<coarse_filter_input>` 标签内提供的【当前日期 (`current_date`)】、【我方目标商品信息 (`my_candidate_product`)】与【闲鱼搜索返回的商品概览列表 (`xianyu_search_items`)】，站在**真实消费者**的视角完成同款初筛与排序，并以标准 JSON 对象格式输出：

1. **同款可比性初筛**：
   - 站在计划购买该商品的真实消费者角度，判断闲鱼概览列表中的每条商品是否属于可与我方目标商品公平折算单价对比的同款全新现货：
     1) **品牌、系列档次与规格体系一致**：闲鱼商品必须与我方目标商品属于同一品牌、同一具体产品系列、同一功能定位档次及对等的型号尺码体系；不得将不同品牌、无品牌、跨产品线档次或明确标注为不同型号尺码的商品视为同款。
     2) **正常邮寄售卖的全新有效实物**：帖子必须为正常面向异地买家邮寄售卖的全新完好正装现货；若概览文本已表明商品相对当前日期 `current_date` 超过保质期、属于拆封使用过的余量或破损瑕疵品、限制仅限同城当面自提拒绝邮寄、声明单件不包邮且无明确包邮组合方案、非正装实物或属于求购引流信息，则一律不予采纳。

2. **按预估含邮性价比排序**：
   - 将通过初筛的可比商品 `item_id` 按照消费者视角下“同款确定性最高、交易与邮寄条件最可靠、预估含邮折算单价最划算”的顺序从前到后排列（系统仅会对排在最前面的前 2 个商品获取完整详情，请务必将最准确且最划算的同款排在最前）。
   - `comparable_item_ids` 中的每个 ID 必须严格来自输入 `xianyu_search_items` 中的 `item_id` 原值，严禁编造或修改。
   - 若没有任何符合条件的可比商品，将 `has_comparable_candidates` 设为 `false`，`comparable_item_ids` 设为 `[]`。

---

## 输出 JSON 格式协议

请仅输出一个合法的 JSON 对象，不要包含任何多余的前缀或后缀说明，字段结构如下：

```json
{
  "has_comparable_candidates": true,
  "comparable_item_ids": ["最优可比商品item_id_1", "次优可比商品item_id_2"],
  "filter_reason": "简明说明站在消费者角度采纳与排除的核心依据（100字以内）"
}
```
