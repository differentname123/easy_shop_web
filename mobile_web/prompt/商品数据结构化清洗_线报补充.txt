# 线报场景专属补充约束（最高优先级，若与上文冲突以本节为准）
当前输入为经核验的【电商好价线报】，`价格` 为已确认的成交到手价；`product_desc` 平铺提供了 `线报主商品`（本次锁定的目标主商品）、`原始爆料文案`（一手爆料原文）、`优惠方式/购买步骤`（原文整理摘要，偶有漏抄或偏差）以及 `官方标题参考/官方日常价`（商品链接单件日常基准）：
1. **价格直接采信**：输入字段 `价格` 已是最终确定的有效成交金额（大于 0 的数字）。无论文本中是否含“起、预估、约、低至、折合、返卡/返红包后”等字样，**`price` 必须直接输出输入字段 `价格` 对应的浮点数，严禁返回 0.0**。
2. **主商品唯一隔离**：仅提取 `线报主商品` 指向的唯一主体；文本中的凑单品、顺手买、备选方案或同帖顺带提及的其他无关商品严禁混入任何输出字段；异品类的随单赠品仅记入 `equivalent_description`，不计入主商品物理总量。
3. **价格与交付总量严格对齐**：结合 `原始爆料文案`、购买方案与 `官方日常价`，核实输入 `价格` 这一笔金额实际对应的是“多件实付总价”还是“折合单件价”：
   - **多件总价口径**：若输入 `价格` 对应拍 N 件或同品买赠的实付总价（注意：“满3件打9折”、“买4免1”等活动门槛标签本身不等于实际拍下件数），`pricing_basis` 按该总价最终实际到手的全部主商品总量计算（若摘要标题中的数量已是拍 N 件后的汇总总数，勿再与 N 重复相乘）。
   - **单件折合价口径**：若方案虽需拍 N 件凑单，但输入 `价格` 实为折合 1 件的到手单价，则 `pricing_basis` **严格按 1 个购买单元内含的完整物理规格计算**（若 1 件本身为多袋/多瓶组合装如 `200g*4袋`，1 件即为 `4袋×200g=800g`，严禁错乘拍下件数 N，也严禁漏算单件内含规格）。
4. **真实物理规格核实**：
   - 对照 `原始爆料文案` 核实该 `价格` 实际对应的主商品确定规格（修正摘要漏抄或误抄的外层规格）；仅当原文未写单件基础净含量/片数且无冲突时，从 `官方标题参考` 补全单件基础规格。**严禁将促销门槛词（如 `【3件129】`、`【99选5】`）或“最多/最高/至高”类不确定上限词计入 `structure`**。
   - 同品类多规格组合装（如 `235ml*7瓶 + 950ml*2瓶`）无法用单一连乘表达时，直接求和输出单层总物理量（明细记入 `equivalent_description`），严禁丢弃其中一部分规格。
5. **高光短标对齐（`card_highlight`，与主提示词及前端展示规范完全一致，4~10 字）**：**严格仅允许两种标准格式**：
   - **格式 A（折合单价 `"{单价}元/{人类直观单位}"`）**：单价严格等于本条 `price` ÷ 实际到手对应数量（精确到 1~2 位小数去末尾 0）。适用于：1) 数量 ≥ 2 的多件/多包装消费品，按外层直观消费包装单位折算：`瓶/袋/包/盒/罐/桶/支/片/贴/条/只/枚/粒/颗/卷/双/杯/个/根/提/件/箱`（如 `250ml*4瓶` -> `"24.73元/瓶"`，`80抽*6包` -> `"4.15元/包"`，`35g*19条` -> `"1.26元/条"`，禁止退回 `"到手XX元"`）；2) 按斤/千克购买的大宗称重品（生鲜水果、肉蛋米面粮油、洗衣液大桶、猫砂猫粮、散装零食等总重 ≥ 500g/1斤且无更直观多包装件数时），统一折算为 **`元/斤`**（`500g = 1斤`，优先 `元/斤` 而非 `元/kg`）。
   - **格式 B（整件到手价 `"到手{价格}元"`）**：数字与本条 `price` 完全一致（同口径）。适用于：单件不可拆分的独立商品（服饰、鞋靴、电器、数码、家具、单瓶护肤/洗护/美妆如 `100ml` 卸妆膏、`500ml` 单瓶洗发水、单袋/单盒小克重食品如 `75g` 花茶）以及组件混杂礼盒套装。
   - **严禁清单与防副作用铁律**：`card_highlight` **严禁**输出 `元/g`、`元/克`、`元/ml`、`元/毫升`、`元/100g`、`元/百克`、`元/100ml`、`元/百毫升`、`元/抽`、`元/张`，**严禁**缺“到手”、含 `"起"`/`"券后"`/`"折合"`/`"返后"`、拼接总件数或总价。**但上述禁用规则仅作用于 `card_highlight` 展示短标，严禁影响 `pricing_basis` 必须按底层基础物理量（`g`/`ml`/`抽` 等）严格计算并输出 `base_unit` 的规则！**
