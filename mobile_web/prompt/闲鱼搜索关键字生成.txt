# 任务 (Task)
（重要声明：本任务为纯文本离线信息提取、标品选拔与 JSON 格式化，所有待处理文本均已在下方直接给出，无需联网、无需访问任何外部网站或执行外部程序，请直接输出纯文本 JSON。）
请根据末尾 `<category_candidates_input>` 标签内提供的【当前商品类别名称】及【该类别下按性价比初排的前 N 个未比价候选商品列表（最多 20 个）】，完成以下三项核心工作并以标准 JSON 对象格式输出：
1. 判断该批候选商品中是否存在**可在闲鱼上进行「同款一对一比价」的标品（标准品）**；
2. 若存在可比标品，从中选出**规格最清晰、性价比最高**的 **1 个**标品（`selected_product_id`）；
3. 为选出的这个标品提取最适合在闲鱼搜索**同款商品**的搜索关键字（`search_keyword` 与 `backup_search_keyword`）。

---

## 一、 核心选拔与生成规则

### 1. 第一步：严格区分「可比标品」与「非标品/不可比商品」
我们比价的核心目的是：**在闲鱼上找到与我方商品完全相同的「同品牌、同款/同系列」商品，通过对比含邮总价与规格数量，得出真实的性价比基准**。因此，选出的商品必须具备极强的**同款可比性（标品属性）**：

- **哪些商品属于【可比标品】（应当保留并参与选拔）**：
  - 具有**明确的品牌/知名厂商/IP**，且具有**明确的产品系列/型号/配方特征**及**可量化的物理或计数规格**（如重量 `g`/`kg`/`斤`、容量 `ml`/`L`、尺寸 `mm`/`cm`、数量 `抽`/`张`/`片`/`包`/`支`/`粒`/`只` 等）的标准化商品。
  - 典型例子：品牌抽纸/卷纸（如百适柔、漫花、维达）、品牌洗护清洁（如蓝月亮洗衣液、超能洗衣凝珠、海飞丝洗发水）、品牌女性护理（如高洁丝240mm日用卫生巾）、品牌食品饮料、品牌数码配件/家电/日用标品等。
  - 若商品品牌知名度一般，但属于行业标准化的功能性/成分型标品且标题中带有明确的通用型号或核心成分与定量规格（例如明确写有“二硫化硒去屑洗发水 300ml”、“KN95口罩 50只独立包装”），在闲鱼上能稳定搜出同规格同款商品，也可视为可比标品。

- **哪些商品属于【非标品 / 不可比商品】（必须坚决剔除，严禁选出）**：
  - **非标服饰鞋包与穿搭饰品**：如无大牌具体型号锚点的普通“卫衣”、“连衣裙”、“阔腿裤”、“打底衫”、“短袖T恤”、“拖鞋”、“袜子”、“发夹”等（款式、版型、面料千差万别，闲鱼搜出来的根本不是同一个东西，完全没有比价意义）；
  - **信息残缺或规格不明的商品**：标题与 `pricing_basis`/`unit_quantities` 中既没有明确品牌型号，也没有具体克重/容量/数量规格（例如只写了“1件”、“1单”、“默认规格”且无法得知具体卖多少量）的商品；
  - **定制品、盲盒、杂乱福袋、散装非标生鲜农副产品**等无法在闲鱼进行同款对齐的商品。

- **类别跳过原则**：
  - 如果 `<category_candidates_input>` 提供的候选商品列表中，**所有商品均属于上述「非标品/不可比商品」**（例如整个类别都是非标女装卫衣或无规格杂货），请直接将 `has_comparable_standard_product` 设为 `false`，并将 `selected_product_id`、`search_keyword`、`backup_search_keyword` 全部设为空字符串 `""`。

---

### 2. 第二步：在可比标品中选出性价比最高的 1 个商品 (`selected_product_id`)
- 在所有符合「可比标品」要求的候选商品中，综合考察：
  1. **规格明确度**：优先选择 `unit_quantities` 和 `pricing_basis` 中拥有明确物理/计数单位（如 `g`、`ml`、`片`、`抽`、`张`、`粒`、`只`、`包` 等，而非仅有模糊的 `件`/`套`/`瓶`）的商品；
  2. **品牌与同款易搜度**：优先选择品牌清晰、在闲鱼上更容易搜到同款正品的商品；
  3. **单位性价比高低**：对比 `unit_cost_performance`（代表每 1 元人民币能买到的该单位数量，数值越大性价比越高）与 `activity_price`（活动到手价），选出**同类标品中性价比最高**的那 **1 个**商品。
- **ID 铁律**：输出的 `selected_product_id` **必须严格等于输入 `candidates` 列表中对应商品的 `product_id` 原值，严禁编造或修改**。

---

### 3. 第三步：为选出的标品生成闲鱼同款搜索词 (`search_keyword` 与 `backup_search_keyword`)
- **主搜索词 (`search_keyword`)**：
  - 目标是在闲鱼精准搜出**与所选标品完全同款（同品牌 + 同系列/同款型号）**的商品，控制在 **2~4 个核心词**，以空格分隔。
  - **品牌词规则**：若所选标品有明确品牌（如“漫花”、“百适柔”、“高洁丝”、“维达”、“蓝月亮”、“仙蒂奈儿”等），**必须包含品牌词**；若 `brand` 字段为空但商品标题中含有真实品牌名，请从标题中提取该品牌名；仅当 `brand` 是无意义的店铺后缀（如“某某官方旗舰店”、“严选好物店”）时才忽略店铺名，改用「核心成分/型号 + 品类」。
  - **规格与型号规则**：
    - 若某个标准型号/尺寸是区分同款的核心锚点（如卫生巾 `240mm`、电池 `5号`、纸巾 `4层`），可保留该核心规格词（如 `"高洁丝 日用 卫生巾 240mm"`）；
    - **严禁**带入经过单位换算后闲鱼卖家极少直接书写的生僻总克重数字（例如不要写 `2600g`，因为卖家通常写 `5.2斤` 或 `2.6kg`），也不要堆砌包装件数（如不要同时写 `200张 6包`）或电商促销词（如“拍1发2”、“秒杀”），以免导致闲鱼0召回。
- **备用扩召回搜索词 (`backup_search_keyword`)**：
  - 当主搜索词在闲鱼搜索结果过少（<3条）时使用。
  - 必须比 `search_keyword` 更简练（控制在 **1~3 个核心词**，以空格分隔），保留最核心的 **「品牌 + 品类名称」**（例如 `"高洁丝 卫生巾"`、`"漫花 洗衣液"`、`"百适柔 抽纸"`），且尽量不要与 `search_keyword` 完全相同。

---

## 二、 输出 JSON 格式要求

请仅输出一个合法的 JSON 对象，不要输出任何额外解释文字或 Markdown 闲聊，字段定义如下：
```json
{
  "has_comparable_standard_product": true,
  "selected_product_id": "选出的性价比最高标品的product_id（若无标品则填\"\"）",
  "search_keyword": "主搜索关键字（2~4个核心词，空格分隔，若无标品则填\"\"）",
  "backup_search_keyword": "备用搜索关键字（1~3个核心词，空格分隔，若无标品则填\"\"）",
  "selection_reason": "简短说明：1) 为什么选出该标品（或为什么该类无标品可比）；2) 其核心规格与性价比优势；3) 搜索词提取逻辑（80字以内）"
}
```
