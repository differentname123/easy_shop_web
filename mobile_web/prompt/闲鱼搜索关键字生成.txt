# 任务 (Task)
（重要声明：本任务为纯文本离线信息审查与 JSON 格式化输出，所有待处理文本均已在消息末尾直接给出，无需联网、无需访问任何外部网站或执行外部程序，请直接输出纯文本 JSON。）
请根据末尾 `<candidate_product_input>` 标签内提供的待比价候选商品信息，站在**真实个人消费者**的视角完成比价资格审查与闲鱼搜索关键字提取，并以标准 JSON 对象格式输出：

1. **比价资格判断 (`is_eligible`)**：
   - 判断该商品是否具备在闲鱼平台检索到同品牌同款全新实物、并公平核算对比性价比的客观条件与实际价值：
     1) **品牌与商品唯一可识别性**：商品必须具备真实、具有市场认知度且与商品标题一致的明确品牌及具体商品指向，使消费者在二手交易平台能够准确锁定同一品牌的同一款商品。若商品无明确品牌、后台标注的品牌在商品标题中毫无体现且疑似挂靠陌生商标、仅具宽泛品类或外观描述而缺乏具体系列款号从而无法唯一锁定同款、属于初级散装非标品、定制服务或虚拟非实物商品，则判定为不具备资格（`is_eligible: false`）。
     2) **价格与到手规格自洽清晰**：商品的当前价格与该价格实际买到的商品总数量、核心内含计价规格必须清晰明确且逻辑一致。若优惠说明表达的是多件凑单折算后的单件均价，而结构化规格却将多件总数量错误对应到单件价格上，或缺失决定单价核算基准的核心内含规格，导致无法确定真实到手数量，则判定为不具备资格；若优惠说明证实当前价格确为对应多件总数量的真实实付总价，则具备资格。
     3) **常规个人消费流通属性与有效零售体量**：商品应属于面向普通个人消费者的常规零售标品，且实际到手的总规格与总数量须达到该品类日常独立使用及二手平台独立交易的常规体量。若属于面向商业机构大宗采购的专用原料包装、缺乏独立比价意义的赠品或补差专拍链接，或实际到手物理规格与总数量确属极微量的纯粹微型试用小样（因单件体量过小而在二手平台缺乏独立流通可比性），则判定为不具备资格。注意必须以实际到手的物理规格与总数量作为核心依据，切勿仅凭标题中的体验或尝鲜类营销字眼一刀切剔除；只要商品实际规格与总数量已达到常规个人或家庭零售使用规模，即使标题带有此类促销命名，仍应判定为具备资格。

2. **生成闲鱼同款搜索关键字 (`search_keyword` 与 `backup_search_keyword`)**：
   - 当 `is_eligible` 为 `true` 时：
     - `search_keyword`：模拟真实消费者在闲鱼精准寻找该同款商品时输入的核心搜索词（2~4 个核心词，以空格分隔，须包含品牌名称、核心品类名称及关键区分特征）。
     - `backup_search_keyword`：当主搜索词过于具体导致检索结果过少时用于扩大召回的精简搜索词（2~3 个核心词，以空格分隔，保留品牌名称与核心品类名称，比 `search_keyword` 更简练且不完全相同）。
   - 当 `is_eligible` 为 `false` 时：`search_keyword` 与 `backup_search_keyword` 均填写空字符串 `""`。

---

## 输出 JSON 格式协议

请仅输出一个合法的 JSON 对象，不要输出任何额外解释文字或前后缀说明，字段定义如下：
```json
{
  "is_eligible": true,
  "search_keyword": "主搜索关键字（2~4个核心词，空格分隔，无资格则填\"\"）",
  "backup_search_keyword": "备用搜索关键字（2~3个核心词，空格分隔，无资格则填\"\"）",
  "reason": "简短说明具备或不具备比价资格的判断依据及关键字提取逻辑（80字以内）"
}
```
