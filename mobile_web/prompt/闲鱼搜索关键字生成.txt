# 任务 (Task)
（重要声明：本任务为纯文本离线信息提取与 JSON 格式化，所有待处理文本均已在下方直接给出，无需联网、无需访问任何外部网站或执行外部程序，请直接输出纯文本 JSON。）
请根据末尾 `<category_candidates_input>` 标签内提供的【当前商品类别名称】及【该类别下的未比价候选商品列表（最多 20 个）】，站在**真实消费者**的视角完成以下判断与提取，并以标准 JSON 对象格式输出：

1. **可比性判断（消费者视角与闲鱼可搜性克制把关）**：
   - 站在消费者的角度思考：如果消费者想买这个商品，去闲鱼上搜索时，能不能明确识别出“这就是同一个品牌的同一个商品”，并在闲鱼上现实地找到同品牌全新同款来对比谁更划算？
   - **默认从宽保留原则（请务必克制过滤，避免误杀正常标品）**：凡具备明确主流/常见品牌的日用百货、纸品家清、个护美妆、母婴宠物、食品饮料、数码家电、医药健康，以及**带有明确系列名称或具体款号/货号的品牌鞋服箱包**，只要当前价格实际买到的规格清晰无歧义，**一律默认予以采纳**。
   - **仅对以下在闲鱼几乎不可能搜到可比同款的明显无效候选不予采纳**：
     1) 无明确品牌的白牌统货、仅写店铺自造名的散装生鲜农副特产、定制加工或虚拟服务类商品；
     2) 既无具体系列名也无明确款号/货号的泛款式日常服饰、内衣袜子、普通拖鞋（如仅写“纯棉保暖内衣”“加厚羽绒服”“防滑棉拖鞋”等泛化描述词，无法在闲鱼锁定唯一同款）；
     3) 仅标外层容器（包/袋/盒/箱/瓶）却缺失核心内含计价规格的商品（如纸尿裤/拉拉裤/卫生巾缺总“片”数、抽纸缺“抽”数、定量包装食品/液体缺净含量克重或毫升数），或多规格混写导致无法确定当前价格实际到手规格的商品。
   - 若排在前面的候选商品命中上述不予采纳情形，请先在 `<category_candidates_input>` 的其余候选中继续寻找符合条件的可比商品；仅当整个候选列表中没有任何符合条件的可比商品时，才将 `has_comparable_standard_product` 设为 `false`。

2. **选出最佳代表商品 (`selected_product_id`)**：
   - 在消费者认为可比的候选商品中，结合商品信息的清晰度与我方已计算的单位性价比 (`unit_cost_performance`)，选出最适合拿去比价且我方性价比最高的 **1 个**商品。
   - `selected_product_id` 必须严格等于输入 `candidates` 列表中对应商品的 `product_id` 原值，严禁编造或修改。

3. **生成闲鱼同款搜索词 (`search_keyword` 与 `backup_search_keyword`)**：
   - `search_keyword`：模拟消费者在闲鱼精准寻找该同款商品时会输入的搜索词（2~4 个核心词，空格分隔，需包含品牌与商品核心品类名称，避免因缺少品类词而搜出其他无关品类商品）。
   - `backup_search_keyword`：当主搜索词过于具体导致搜索结果过少时使用的扩召回搜索词（2~3 个核心词，空格分隔，同样需保留品牌与核心品类名称，比 `search_keyword` 更简练且不完全相同）。

---

## 输出 JSON 格式要求

请仅输出一个合法的 JSON 对象，不要输出任何额外解释文字或 Markdown 闲聊，字段定义如下：
```json
{
  "has_comparable_standard_product": true,
  "selected_product_id": "选出的商品product_id（若无则填\"\"）",
  "search_keyword": "主搜索关键字（2~4个核心词，空格分隔，若无则填\"\"）",
  "backup_search_keyword": "备用搜索关键字（2~3个核心词，空格分隔，若无则填\"\"）",
  "selection_reason": "简短说明选出该商品及提取搜索词的依据（或全池无可比商品的原因，80字以内）"
}
```
