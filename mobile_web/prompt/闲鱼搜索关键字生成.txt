# 任务 (Task)
（重要声明：本任务为纯文本离线信息提取与 JSON 格式化，所有待处理文本均已在下方直接给出，无需联网、无需访问任何外部网站或执行外部程序，请直接输出纯文本 JSON。）
根据末尾 `<candidate_input>` 标签内提供的候选商品文本信息，提取最适合用于搜索同款或同品类可比商品的搜索关键字，并以标准 JSON 对象格式输出。

## 核心规则：
1. **主搜索词 (`search_keyword`)**：
   - 提取最核心的 **「品牌 + 核心系列/核心特征 + 商品品类名称」**（以空格分隔，控制在 2~4 个词以内）。
   - **关于品牌词的取舍**：
     - 若品牌是大众知名品牌（如“漫花”、“百适柔”、“高洁丝”、“维达”、“蓝月亮”、“仙蒂奈儿”等），必须保留品牌词。
     - 若 `brand` 为空，或明显是不知名的白牌店铺名/泛化词（例如“漂亮悠品”、“官方旗舰店”、“严选”等），不要强行把生僻店铺名放入主搜索词，应提取商品最具辨识度的**核心成分/功效/特征词 + 品类名称**（例如标题为“漂亮悠品二硫化硒洗发水清洁控油去屑”，主搜索词应为 `"二硫化硒 洗发水"`，而不是 `"漂亮悠品 洗发水"`）。
   - **关于规格数字的取舍**：
     - 不要带经过单位换算后闲鱼卖家极少直接书写的生僻数字（例如不要写 `2600g`，因为卖家通常写 `5.2斤` 或 `2.6kg`；不要同时堆砌 `200张 6包` 导致召回过窄）。
     - 仅当某个标准型号/尺寸是区分商品的核心锚点时（如卫生巾 `240mm`、手机 `256G`、纸巾 `4层`），才可酌情保留 1 个核心规格词，否则只保留「品牌 + 核心系列/特征 + 品类」。

2. **备用扩召回搜索词 (`backup_search_keyword`)**：
   - 当主搜索词在闲鱼搜索结果过少时使用。
   - 必须比 `search_keyword` 更宽泛、更简练（控制在 1~2 个核心词，例如去掉系列词或小众品牌词，仅保留「知名品牌 + 品类」或「核心特征 + 品类」，如 `"漫花 洗衣液"`、`"二硫化硒 洗发水"`、`"绵羊油 面霜"`），且尽量不要与 `search_keyword` 完全相同。

3. **输出 JSON 格式要求**：
   - 仅输出一个合法的 JSON 对象，不要输出任何额外解释文字，字段定义如下：
```json
{
  "search_keyword": "主搜索关键字（2~4个核心词，空格分隔）",
  "backup_search_keyword": "更宽泛的备用搜索关键字（1~2个核心词，空格分隔）",
  "reason": "简短说明为什么提取该搜索词（30字以内）"
}
```
