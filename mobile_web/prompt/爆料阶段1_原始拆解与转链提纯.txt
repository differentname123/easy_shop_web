# 任务 (Task)
将消息末尾 `<deal_stage1_input>` 标签内传入的原始好价爆料任务列表，解析为极简、确定性的 JSON 数组（List）。
遵循“代码能稳定实现的绝不交给模型”原则：正文的无损拼接、原始活人感话术保留与晒单图片汇总均由下游确定性代码完成。
本阶段（AI 阶段 1）**负责两项纯语义决策**：
1. **精准拆解独立的淘/京/拼待转链目标 (`extracted_targets`)**：将混合在中文句子里的网址、淘口令、京口令、加密商品 ID 逐个剥离提取出来。
2. **极简质量初评与到手价 (`tutorial_score` & `deal_price`)**：
   - `tutorial_score`（0~100 整数，教程与作业实操性打分）：
     - 0~40分：纯水贴或仅有一句商品名加短链，无任何实操指引；
     - 50~70分：包含简要优惠说明（如“直降”、“领券立减”）；
     - 75~100分：包含明确凑单作业、领券顺序、满减门槛、可退说明等详尽实操步骤。
   - `deal_price`（数字或 null）：线报正文中明确提及的主商品预估实付/到手价数值（如 29.9），未提及或含糊不清填 null。

---

## 核心规则（必须严格遵守）：
1. **输出格式**：严格输出合法的 JSON 数组（List），数组元素与输入任务通过 `main_tip_id` 一一对应，禁止输出任何 JSON 以外的解释文字。
2. **待转链目标 (`extracted_targets`) 提纯与平台准入**：
   - **仅提取淘宝/天猫 (`taobao`)、京东 (`jd`)、拼多多 (`pdd`) 三大平台的有效目标**：
     - 电商长短链：`u.jd.com`、`3.cn`、`item.jd.com`、`jingfen.jd.com`、`union-click.jd.com`、`coupon.m.jd.com`、`pro.m.jd.com`、`m.tb.cn`、`s.click.taobao.com`、`uland.taobao.com`、`item.taobao.com`、`detail.tmall.com`、`yangkeduo.com`、`p.pinduoduo.com` 等；
     - 淘口令（含 `￥...￥` / `$...$` / `(...)` / `/.../` 及 `CZ` / `MF` / `HU` 等口令串）、京口令（含 `！...！` / `!...!` / `CA` / `MF` 等）、淘宝加密商品 ID（35~55 位含字母数字下划线或中划线串）、京东加密 ID、拼多多 `goods_sign`。
   - **严禁提取以下内容**（若无任何淘/京/拼目标，输出 `"extracted_targets": []`）：
     1. 任何 `.jpg`/`.jpeg`/`.png`/`.gif`/`.webp` 图片链接；
     2. 线报源站自身网址（`guangdiu.com/go.php`、`new.xianbao.fun`、`youhui.bacaoo.com`、`0818tuan.com`、`iehou.com` 等）；
     3. 与当前淘/京/拼主商品交易无关的独立外部实体外链（如银行办卡活动、外卖本地生活、社媒关注引流、网盘资料分享、应用商店下载等）。
   - **前置优惠与领券链接提纯铁律**：
     凡在文案中明确承担【领券 / 领补贴 / 领红包 / 会场入口】等前置优惠动作的有效 URL 或口令，即使其表面为第三方转发跳转短链，只要是达成当前淘/京/拼商品优惠价格的必要组成部分，必须一律提取并标记为 `"text_role_hint": "coupon_candidate"`（其 `platform` 优先继承主商品的平台归属），交由下游通用安全解包器统一核验其最终落地页合法性，严禁将其视为无关外链提前丢弃！
   - **多链接/多口令强制独立拆分**：一句话内连续出现多个 URL 或多个口令时，必须拆分为多个独立的 `extracted_targets` 元素，按出现顺序编号 `"L1"`, `"L2"`, `"L3"`...
   - **字段精准定义**：
     - `raw_span`：该链接或口令在 `content` 中出现的**精确原始子串**（包含口令自带的数字前缀、`Fu🌹zhi...打開/` 或 `复制...打开手淘` 等防屏蔽口令外壳及 `CZ4176/` 等后缀壳，例如 `"1(nGXV6XvBypV) CZ4176/"`、`"7Fu🌹zhiHU7177,打開/"` 或 `"https://u.jd.com/aaa111"`；**严禁把周围的教程步骤说明词如“先领券”、“拍1件”包含进 `raw_span`**）；
     - `clean_input`：剥离粘连汉字、HTML 标签及 `[...](...)` / `[口令:...]` 语法壳后的**纯净单个裸 URL 或单个完整口令**（如 `"https://u.jd.com/aaa111"` 或 `"1(nGXV6XvBypV) CZ4176/"`）；
     - `platform`：只能是 `"jd"`、`"taobao"` 或 `"pdd"`；
     - `text_role_hint`：只能是 `"coupon_candidate"`（领券/补贴/红包/礼金/会场）、`"main_candidate"`（主推商品）或 `"filler_candidate"`（凑单品/加购退辅助单品；必须照常提取以精准剥离其原始链接/口令并供下游识别凑单动作，下游将自动跳过其转链）。**【纯凑单参考防漏铁律】无论整条帖子是不是只含 1 个链接，只要文案本身仅在推荐“给楼上/他人主商品搭配的凑单品/辅助凑单参考”（例如 `"☝楼上XX凑单参考"`、`"凑单品加车1件"`、`"凑1件用消费券"`、`"拍完退掉凑单"`，本身并不是独立推荐购买的好价主品），其链接必须一律标为 `"filler_candidate"`，严禁标为 `"main_candidate"`！注意：淘宝/天猫二合一领券购买链接（如 `uland.taobao.com/coupon/edetail`，链接文字常含商品名与券后价）本质是直达具体商品页的主购链，必须标为 `"main_candidate"` 而非 `"coupon_candidate"`；文末附带的异平台高价对比商品链不要抢占主推平台归属。**
   - **外部非转链跳转串与第三方引流标记 (`strip_spans`，可选数组)**：若 `content` 中含有未进入 `extracted_targets` 的线报源站跳转链接、外部导购短链、孤立残缺口令壳（如 `"guangdiu.com/go.php?id=123"`），或明确的第三方私域微信号/客服联系方式（如 `"有问题加客服: xhhc6688"`、`"加V: xxx"`），将其精确原始子串放入 `"strip_spans": [...]`（无则省略或输出 `[]`），供下游从展示文案中一并剥离。
