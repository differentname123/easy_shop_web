# 任务 (Task)
将消息末尾 `<deal_stage1_input>` 标签内传入的原始好价爆料任务列表，解析为极简、确定性的 JSON 数组（List）。
遵循“代码能稳定实现的绝不交给模型”原则：正文的无损拼接、原始活人感话术保留与晒单图片汇总均由下游确定性代码完成。
本阶段（AI 阶段 1）**只负责两项纯语义决策**：
1. **同群连续消息归属判定 (`is_standalone_deal` & `merged_tip_ids`)**：当 `is_group_stream` 为 `true` 时，判断前后相邻群消息中哪些属于同一商品作业的前置券、凑单品、口令补充或实付晒单图；若当前主消息 (`main_tip_id`) 本身只是其他主帖的纯附属尾巴，则判定 `is_standalone_deal: false`。
2. **精准拆解独立的淘/京/拼待转链目标 (`extracted_targets`)**：将混合在中文句子里的网址、淘口令、京口令、加密商品 ID 逐个剥离提取出来。

---

## 核心规则（必须严格遵守）：
1. **输出格式**：严格输出合法的 JSON 数组（List），数组元素与输入任务通过 `main_tip_id` 一一对应，禁止输出任何 JSON 以外的解释文字。
2. **连续消息合并法则（宁缺毋滥，严禁捏合两个不同商品）**：
   - 当 `is_group_stream == false`（普通网页/排行榜独立单帖）时：`raw_messages` 仅有 1 条消息，必须设置 `is_standalone_deal: true`，`merged_tip_ids` 仅含 `[main_tip_id]`。
   - 当 `is_group_stream == true`（采集群实时消息流）时，`raw_messages` 含当前主消息（`is_target == true`）及同群前后 3 分钟内的相邻消息：
     - 若当前主消息本身**不含任何主推商品信息**，仅是上一条消息的纯附属碎片（如仅写 `"2、凑单商品拍1件 https://..."`、孤立口令、纯文字补充 `"记得勾选200-20"` 或纯晒单截图），必须设置 `is_standalone_deal: false`，`"merged_tip_ids": [main_tip_id]`，`"extracted_targets": []`。
     - 若当前主消息包含明确的主推商品爆料，仅允许合并与该主商品**明确属于同一次作业**的纯附属碎片（前置领券楼层、明确标“凑单/加购退”的辅助楼层、紧随其后的孤立口令补充楼层、该商品的实付晒单楼层）。
     - **【铁律】严禁将同群内各自带有独立商品名/品牌的两个不同商品爆料合并为一条！** 只要邻居消息讲述的是另一款独立商品，绝对禁止并入 `merged_tip_ids`，也绝对禁止提取邻居消息里的链接！拿不准时一律不合并（仅保留 `[main_tip_id]`）。
3. **待转链目标 (`extracted_targets`) 提纯与平台准入**：
   - **仅提取淘宝/天猫 (`taobao`)、京东 (`jd`)、拼多多 (`pdd`) 三大平台的有效目标**：
     - 电商长短链：`u.jd.com`、`3.cn`、`item.jd.com`、`jingfen.jd.com`、`union-click.jd.com`、`coupon.m.jd.com`、`pro.m.jd.com`、`m.tb.cn`、`s.click.taobao.com`、`uland.taobao.com`、`item.taobao.com`、`detail.tmall.com`、`yangkeduo.com`、`p.pinduoduo.com` 等；
     - 淘口令（含 `￥...￥` / `$...$` / `(...)` / `/.../` 及 `CZ` / `MF` / `HU` 等口令串）、京口令（含 `！...！` / `!...!` / `CA` / `MF` 等）、淘宝加密商品 ID（35~55 位含字母数字下划线或中划线串）、京东加密 ID、拼多多 `goods_sign`。
   - **严禁提取以下内容**（若无任何淘/京/拼目标，输出 `"extracted_targets": []`）：
     1. 任何 `.jpg`/`.jpeg`/`.png`/`.gif`/`.webp` 图片链接；
     2. 线报源站自身网址（`guangdiu.com/go.php`、`new.xianbao.fun`、`youhui.bacaoo.com`、`0818tuan.com`、`iehou.com` 等）；
     3. 非淘/京/拼三大平台的外链（银行活动、美团、饿了么、滴滴、唯品会、抖音、小红书、微信公众号、网盘、B站等）。
   - **多链接/多口令强制独立拆分**：一句话内连续出现多个 URL 或多个口令时，必须拆分为多个独立的 `extracted_targets` 元素，按出现顺序编号 `"L1"`, `"L2"`, `"L3"`...
   - **字段精准定义**：
     - `raw_span`：该链接或口令在 `content` 中出现的**精确原始子串**（包含口令自带的数字前缀和 `CZ4176/` 等后缀壳，例如 `"1(nGXV6XvBypV) CZ4176/"` 或 `"https://u.jd.com/aaa111"`；**严禁把周围的中文说明词如“先领券”、“拍1件”包含进 `raw_span`**）；
     - `clean_input`：剥离粘连汉字、HTML 标签及 `[...](...)` / `[口令:...]` 语法壳后的**纯净单个裸 URL 或单个完整口令**（如 `"https://u.jd.com/aaa111"` 或 `"1(nGXV6XvBypV) CZ4176/"`）；
     - `platform`：只能是 `"jd"`、`"taobao"` 或 `"pdd"`；
     - `text_role_hint`：只能是 `"coupon_candidate"`（领券/补贴/红包/礼金/会场）、`"main_candidate"`（主推商品）或 `"filler_candidate"`（凑单品/加购退单品）。

```json
    "main_tip_id": "xb_101",
    "is_standalone_deal": true,
    "merged_tip_ids": ["xb_101", "xb_102"],
    "extracted_targets": [
      {
        "link_id": "L1",
        "raw_span": "https://u.jd.com/aaa111",
        "clean_input": "https://u.jd.com/aaa111",
        "platform": "jd",
        "text_role_hint": "coupon_candidate"
      },
      {
        "link_id": "L2",
        "raw_span": "https://u.jd.com/bbb222",
        "clean_input": "https://u.jd.com/bbb222",
        "platform": "jd",
        "text_role_hint": "main_candidate"
      },
      {
        "link_id": "L3",
        "raw_span": "https://u.jd.com/ccc333",
        "clean_input": "https://u.jd.com/ccc333",
        "platform": "jd",
        "text_role_hint": "filler_candidate"
      }
    ]
  }
]
```
