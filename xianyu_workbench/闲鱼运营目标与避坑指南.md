## 零、核心分析铁律：看日均速度与同龄对照，严防“活得久错觉”（最高前置原则）

> **为什么这条必须写在最前面？**  
> 在闲鱼，`累积浏览 = 日均浏览速度 × 存活天数`。直接看总浏览量、总想要数，会把“日均只来 `1` 个人看、但硬挂了一两年的老链接”误判成流量赢家，从而导出完全相反的运营动作。

* **本库真实衰老曲线**（通过 `1~28天内降价` 边界标定 `item_id` 时间增速约 `~2.73 亿 ID/天`，叠加 `X小时前发布` 校准 `n=1,094` 详情）：
  * `≤ 3 天`（新品期）：日均浏览 **`15.00 / 天`**；
  * `3 ~ 45 天`：日均浏览 **`3.26 ~ 3.49 / 天`**，日均想要 `0.11 ~ 0.14 / 天`；
  * `45 ~ 120 天`：日均浏览降至 **`2.25 / 天`**，日均想要 `0.09 / 天`；
  * `120 ~ 365 天`：日均浏览跌至 **`0.89 / 天`**，日均想要 `0.04 / 天`；
  * `> 365 天`（老古董）：中位活了 **`666.5 天`**，累积浏览看着高达 `648`，实际日均只有 **`1.03 / 天`**。
* **被“活得久错觉”直接推翻的 4 个常见误判**（后续复盘严禁再犯）：
  1. `7~9 张图` 累积浏览看似是 `2~3 张图` 的两倍，实因前者活了 `112.6 天`、后者仅 `46.1 天`；按日均和同龄组看，**`2~4` 张图反而最快**；
  2. `累计降价X%`（`≥10%`）看似流量高，实因中位活了 `175.0 天`，日均浏览仅 `1.50/天`，**不如不降价（`2.14/天`）**，真正提速的是 **`<10%` 真实微降（`3.69/天`）**；
  3. “所有出单老链都该死守”是错的：只有**想要率 `≥ 8%`** 的真爆款才能抗住时间衰减（`31~120 天` 仍保持 `11.86/天`）；想要率 `< 5%` 的老链越老越死，留着纯占坑；
  4. 单品凑“1 份 / 2 份”阶梯多规格看着累积想要多，主要沾了深库存+活得久（`129 天`）的光；按同龄 `≤ 30 天` 看，它**不比单 SKU（`q>1`）日均曝光更高**，真正拉爆日均曝光与想要双指标的是**真多款式 / 多型号**多规格。
* **统一复盘标尺**：以后所有分析，只看 **`日均浏览 (B/day)`、`日均想要 (W/day)`、`同龄切片`、`snapshots 区间实时增量`** 以及 **年龄无关的 `想要率 (want / browse)`**。

## 核心总纲：唯一值得追的日均效率飞轮

```text
守住三层风控底线 + 正常放开合规选品（普通个人号起步）
   ↓
冷启动死磕「想要率 ≥ 8%」（5%~8% 及格 / ≥8% 抗衰减） ──→ 靠有竞争力的真价 + 2~4 张精选首图 + >200 字高信息密度文案
   ↓
快速承接与履约（90%+ 回复率 / 1~5 分钟首响 / 24h 发货 48h 揽收）──→ 积累好评（守住 90%+）与信任标签
   ↓
真爆款（wr≥8%）深库存/备链死保 + 平庸链（wr<5%）7~14天淘汰重发吃新品期 + 匀速上新 ──→ 最大化全店日均出单速度
```

## 一、明确「要达成」的 8 大全链路运营目标

### 目标 1：冷启动期直接打高「想要率」（及格线 `5%~8%`，抗衰减爆款线 `≥ 8%`）【L1 实证】
- **核心动作**：新链接上架初期不以虚高价格劝退买家，直接给出有市场竞争力的真实价格，配合清晰首图与一眼看懂的规格卖点，在冷启动窗口内冲过 `8%` 想要率门槛。
- **日均速度 + 分层实证依据**（固定 `browse_cnt ≥ 30` 消除分母极小偏差，`n=827`）：
  - `想要率 < 2%`（`n=127`）：`B/day = 1.19` / `W/day = 0.00` / 爆款率 **`0.0%`**（死水池）；
  - `2% ~ 5%`（`n=270`）：`B/day = 2.26` / `W/day = 0.08` / 爆款率 `3.3%`；
  - `5% ~ 8%`（`n=229`）：`B/day = 3.01` / `W/day = 0.19` / 爆款率 **`13.5%`**；
  - `8% ~ 12%`（`n=138`）：`B/day` 跃升至 **`7.42`** / `W/day = 0.70` / 爆款率 **`39.1%`**；
  - `≥ 12%`（`n=63`）：`B/day` 高达 **`8.70`** / `W/day = 1.35` / 爆款率 **`47.6%`**。
  - **抗衰减实证**：`wr ≥ 8%` 链接在 `31~120 天` 仍保持 `B/day = 11.86 / W/day = 1.27`，几乎不随时间衰减。

### 目标 2：按品类阶段务实选择链接形态（先保不断流，再看真多款式 vs 份数阶梯）+ 默认包邮【L1 实证纠偏】
- **核心动作（三档清晰分工）**：
  1. **真多款式 / 多口味 / 多型号商品**（如多口味饮料、多尺寸家电）：**必须合并为一个多规格主链接**，同时把 SKU 价差控制在 **`1.0x ~ 3.0x`**，集中承接多路搜索词与人群；
  2. **纯单品且具备深库存条件（`q > 1`）**：老老实实单 SKU 深库存上量即可，日均曝光完全不吃亏；
  3. **纯单品设「1 份装 / 2 份装」阶梯**：若当前号顺手可设、且上游**2 份折合单价真更低**，可作为稳住想要率与拉高客单的小加分项；**但没必要为了设 1份/2份 而提前开鱼小铺多交 1% 费率**；
  4. **坚决不做“全同价/同义凑数假多规格”**：系统不给多规格按钮白送流量，同价凑数反而拉低想要率；
  5. **默认包邮**：全库 `90.4%` 包邮，详情爆款组包邮率 **`100.0%`**。
- **同龄日均速度实证依据**（`n=1,094`）：
  - **`≤ 30 天` 同龄组**：
    - `多规格 · 真多款式/型号`：**`B/day = 14.55 / W/day = 1.58 / 想要率 9.1%`**（断层第一）；
    - `单 SKU 深库存 (q>1)`：**`B/day = 6.06 / W/day = 0.22 / 4.3%`**；
    - `单 SKU 单库存 (q=1)`：`B/day = 5.17 / W/day = 0.10 / 2.6%`；
    - `多规格 · 1份/2份份数阶梯`：`B/day = 3.55 / W/day = 0.25 / 6.2%`（**曝光低于单 SKU，仅想要率稳定在 `6.2%` 且略微抬高日均想要**）；
    - `多规格 · 全规格同价`：`B/day = 3.97 / W/day = 0.33 / 5.6%`（在全库各卖家分层里想要率均略低于单 SKU 深库存）；
  - **`31~180 天` 同龄组**：`真多款式`（`4.35 / 0.20 / 7.0%`） > `单 SKU (q>1)`（`2.58 / 0.10 / 4.3%`） > `单 SKU (q=1)`（`1.42 / 0.06 / 3.9%`），`份数阶梯` 为 `1.04 / 0.06 / 6.7%`；
  - **SKU 价差区间**：`1.0~1.5x` 爆款率 `23.2%`、`1.5~3.0x` 爆款率 `26.9%`；拉大到 `3.0~10x` 跌至 `14.3%`。

### 目标 3：关键词对齐搜索、`> 200` 字高信息密度文案 + `2~4` 张精选首图/细节图【L1 实证纠偏 + L3 实测】
- **核心动作**：
  1. **首行即标题（前 15–30 字）**：用「品牌通用名 + 核心品类/型号 + 关键规格/卖点」对齐闲鱼搜索下拉词；
  2. **高信息密度长描述（目标 `> 200` 字，拒绝空话）**：把实得精确规格、自然单位折合单价、官方直发/全新批次、核心材质/功效/实用场景、以及透明发货与偏远邮差边界一次写透；
  3. **结构化属性标签（`cpv_labels`）填准 `1~2` 个核心属性即可**（如 `成色：全新`、`剩余保质期`、`购买渠道`）；
  4. **图片数量控制在 `2~4` 张精选高质量图**（避开只有 1 张图，也无需硬凑 9 张废图）；优先使用 **3:4 竖图生活化实拍首图** + **10–15 秒实物动态视频**（`[L3 实测]`，待后续新采集的宽高/视频字段直接回测验证）。
- **同龄日均速度实证依据**（`n=1,094`）：
  - **正文长度（经受住同龄检验的最稳加速器）**：
    - `≤ 30 天` 同龄组：`>200 字` 日均想要 **`0.35`**（想要率 `5.8%`），远高于 `≤200 字` 各组（`0.08 ~ 0.13`）；
    - `31~180 天` 同龄组：`>200 字` 日均浏览 **`4.79`**、日均想要 **`0.26`**，而 `≤200 字` 仅 `1.60 ~ 1.81` / `0.06 ~ 0.08`（**日均效率翻近 3 倍**）；
  - **图片数量（日均速度纠偏）**：
    - 全盘日均：`2~3 图` **`B/day = 3.32 / W/day = 0.11`**（第一） > `1 图`（`2.03 / 0.06`） > `4~6 图`（`1.97 / 0.08`） > `7~9+ 图`（`1.86 / 0.08`）；
    - `≤ 30 天` 同龄组：`2~3 图` **`B/day = 7.51 / W/day = 0.27`** 断层第一，`1 图` 最差（`3.07 / 0.06`），`7~9+ 图` 仅 `3.93 / 0.18`；`31~180 天` 同龄组仍以 `2~3 图`（`2.14 / 0.10`）最高；
  - **属性标签**：`1~2` 个核心标签组爆款率 `18.6%` 最高，高于 `0` 个（`8.7%`）和 `3+` 个（`6.5%`）。

### 目标 4：抢占「响应时效」与「发货揽收」双底线，锁定转化并积累信任标签【L1 实证 + L2/L3 核验】
- **核心动作**：
  - **回复指标目标**：保持 **24 小时回复率 `≥ 90%`**、**1~5 分钟内人工有效响应**（抢在同时问 3~5 家的买家流失前锁单），点亮 **`回复超快`** 与前台 **`刚刚来过 / X分钟前来过`** 活人背书；忙时可用**官方保守快捷短语**兜底，不在高客单/非标品开 AI 自由议价；
  - **履约指标目标**：尽量做到 **24 小时内发出、48 小时内产生真实物流揽收轨迹**，争取 **`发货极快`** 标签；
  - **信用目标**：维持 **芝麻信用极好（700+）** 与 **`卖家信用极好`** 标签。
- **日均速度与分层实证依据**：
  - 全盘日均（`n=1,094`）：`回复超快` 组 `B/day = 3.33 / W/day = 0.12` vs 非超快组 `1.98 / 0.07`；`发货极快` 组 `B/day = 11.00`（样本 `n=11` 偏少，属高敏信号待续采验证）；
  - **分层客观事实**：在 `≤30 天` 新链接和中小卖家组，单个标签本身不会替烂品直接凭空制造浏览，核心价值在于 **1~5 分钟锁住询单转化率**、**防止“高咨询零成交”拉垮模型排序**以及高销量阶段复利。

### 目标 5：顺势用「真实微降（`<10%`）」激活关注池，抛弃“先涨后降满 10%”执念【L1 实证纠偏】
- **核心动作**：
  - 冷启动永远**直接用有竞争力的真实低价开局**；
  - 当链接已攒下一定「想要/收藏」，且确有真实降本、清尾或促销让利空间时，执行一次**真实微降（通常降几元即可，`累计降价X元`）**，触发系统对关注买家的 Push 唤醒与降价检索曝光；
  - 仅在本身毛利弹性极足时才顺势跨 `≥10%`，绝不为了凑百分比大标而先虚高起价。
- **日均速度与实证依据**：
  - 全盘日均（`n=1,094`）：**`累计降价X元`（`<10%` 实降）`B/day = 3.69 / W/day = 0.23 / 想要率 6.1%`**（日均想要是不降价和降满 `10%` 的 **3 倍**）；
  - 反观 **`累计降价X%`（`≥10%`）**：中位存活高达 **`175.0 天`**，日均速度仅 **`B/day = 1.50 / W/day = 0.07`**，日均浏览甚至低于不降价组（`2.14 / 0.07`）；
  - 进入 `/search`「新降价」（`sortField="reduce"`）比对的是上架后真实调价轨迹，不依赖填 `originalPrice`（全库 `81.5%` 未填更高原价）。

### 目标 6：以「想要率 `8%`」为分水岭——保真爆款、快淘平庸链、匀速吃新品期【L1 实证纠偏】
- **核心动作**：
  - **真爆款（`想要率 ≥ 8%` 或持续出单）**：绝不轻易删掉，必须靠深库存或**提前布局差异化备链**保不断流（它 4 个月内几乎不衰减）；
  - **平庸链（上架 `7~14` 天，想要率 `< 5%` 或日均浏览 `< 1~2`）**：**果断下架或删除，换首图、改文案、调价格重发**，重新抢占 `≤3天` 新品期 `15/天` 的冷启动流量窗口；
  - **匀速上新**：每天稳定上新 **`2~5` 个**（分散在早 `8–10` / 午 `12–14` / 晚 `18–21` 高峰），不一次轰炸后长期断更；
  - **付费只放大已验证爆款**：自然流里已证明 `想要率 ≥ 8%` 的款，才用小额「超级擦亮 / 大鱼推广（`dayu.goofish.com`）」按点击/咨询目标放大。
- **日均速度实证依据**：
  - `wr ≥ 8%` 组：`≤30 天` `B/day = 14.29 / W/day = 1.58` → `31~120 天` **`11.86 / 1.27`**（抗衰减）；
  - `wr < 5%` 组：`≤30 天` `6.70 / 0.14` → `31~120 天` 跌至 `2.04 / 0.05` → `>120 天` 跌至 **`0.68 / 0.02`**（死水占坑）；
  - 全库 `≥100` 想要爆款中 `92.9%` 出自有过历史评价的卖家（卖家中位已售 `5,188` 单 vs 低想要组 `709` 单）。

### 目标 7：严守账号健康度（`闲气值 > 80`、好评率 `≥ 90%`、低纠纷退款率）【L1 实证 + L2 官方】
- **核心动作**：
  - 守住 `闲气值 81~100` 安全区间；
  - 严防好评率跌破 `90%` 与「描述不符 / 缺货 / 假冒」责任退款：拍错/不想要引导选买家自身原因，遇恶意纠缠在运费可控时退货止损，不硬刚换差评或小法庭败诉；
  - 易争议/高客单品：发货前站内聊天让买家确认关键细节，贵重品留一镜到底打包视频，所有退款只走平台线上正规流程。
- **日均速度与官方依据**：
  - **闲气值阶梯（`2026-11-01`《闲鱼社区管理规范（试行）》）**：`闲气值 = 100 - 近90天扣分`。`81~100` 无限制；`61~80` **全店下架 + `7` 天禁发禁互动**；`31~60` 停 `14` 天；`1~30` 删光商品停 `21` 天；`0` 分永久限制；
  - **好评率断崖线（`n=1,094`）**：`100%`（`B/day=2.57 / W/day=0.09`）、`98%~99%`（`2.25 / 0.09`）、`90%~97%`（`2.17 / 0.09`）均保持正常速度；**一旦跌破 `90%`（`1%~89%` 组）**，即便卖家历史已售中位数高达 `12,066` 单，日均浏览仍腰斩至 **`0.97 / 天`**、日均想要跌至 **`0.04 / 天`**；
  - **不盲开 7 天无理由（`n=1,094`）**：本库中 `nfrIcon` 与 `sevenIcon`（支持 7 天无理由）**严格互斥（`both=0`）**；`nfrIcon` 日均速度 **`B/day = 3.01 / W/day = 0.12`**，而 `sevenIcon` 仅 **`1.24 / 0.06`**（仅为非 7 天无理由组 `2.33` 的一半）。

### 目标 8：按阶段权衡「普通个人号 `0.6%` 红利」与「鱼小铺 `1.6%` 工具权限」【L2 官方 + L1 实证】
- **官方费率硬约束（`2026-04-18`《软件服务费收费规则》& `2026-03-05`《鱼小铺工具管理规范》）**：
  - **普通个人号**：基础费率 **`0.6%`**（单笔 **60 元封顶**）；仅当同一自然月成交 **`>10` 笔且 `>10,000` 元** 后，超出部分加收 `1%` 至 `1.6%`；
  - **鱼小铺**：自首单起全额（含实付、运费、补贴）统一 **`1.6%`**，且**取消 60 元封顶**；退出后若重开，**`90` 天内不可再退出**；
  - **退款退费边界**：确认收货前线上正规全额退款退还服务费；**确认收货后退款或线下私下退款一律不退**。
- **阶段决策原则**：
  - **起盘测品 / 单店月成交不大 / 高客单薄利品类**：**坚决不开鱼小铺**，死守普通号 `0.6%`（60 元封顶）与个人闲置售后边界（且鱼小铺无自然流量加权）；
  - **已跑通高频爆款（尤其是真多款式/多型号需深库存持续蓄水）、单量突破普通号限制且毛利足以覆盖多出的 `1%` 费率与售后成本时**：再升级鱼小铺或正规主体承接。

## 三、解除多余焦虑 vs 真正不能暴露的「三层风控检测面」

闲鱼现实执法不是“条款写了就秒杀”，而是按**三层不同触发逻辑的漏斗**运作：
1. **第 1 层：AI 机审事前拦截**（硬违禁词、站外导流图文、极端 SKU 价差、深度学习视觉同图聚类、毫秒级机器脚本——**触线即秒删/限流**）；
2. **第 2 层：大数据行为画像**（设备/IP 群控关联、2026 经营性卖家 5 项量化特征——**不按单条秒杀，看累计画像决定是否弹窗限权或要求补照**）；
3. **第 3 层：被动投诉触发**（买家不满意举报、同行恶意举报、品牌法务巡查扫号——**平时未撞机审时“事实存活”，一旦惹出投诉几乎无申诉空间**）。

### 3.1 可以放心卖、不要自己吓自己的边界【L1 实证】
- **预包装食品、饮品、正规美妆护肤、日化洗护、宠物用品统统可以正常卖**：
  - 本库 `15,236` 条真实线上数据中，**食品/饮品占 `19.5%`（`2,972` 条，`≥100` 想要 `251` 个，最高 `9,223` 想要）**，**美妆/护肤/洗护占 `7.2%`（`1,103` 条，`≥100` 想要 `113` 个，最高 `4,964` 想要）**；
  - 文案出现普通“正品”字样全库达 `5,378` 条（`35.3%`），并非机审秒杀词（真正高危的是“绝对/100%正品、假一罚万、全网最低”或引来品牌方投诉的低价大牌）；
  - 遇到 PC 端提示个别受限类目时，按工作台机制自动切回「其他闲置」并过 `prepubcheck` 预检即可正常发布。

### 3.2 至少绝对不能被系统或买家发现的 6 条反检测边界【L1/L2/L3 实证】

| 业务动作 | 真实检测方 | 绝对不能暴露的检测特征 | 必须守住的操作底线 |
|---|---|---|---|
| **同款/多链内容复用** | 阿里 CNN 视觉特征向量 + NLP 语义查重 | 直接用网图/电商白底图，或只做改 MD5、加边框、轻调色镜像（视觉向量仍会聚类）；多链文案高度雷同；1 小时内密集轰炸发几十个同款。 | 做到**物理构图/角度/背景/主图排序实质差异** + 文案语义重构 + 分时段匀速发，不靠铺同款内耗。 |

| **隐形限流自检（不盲猜）** | 静默降权状态（不弹窗扣分） | 全店或单品曝光突然跌至 `0` / 个位数。 | 用**另一台手机 + 非同一账号 + 手机流量**按“最新”搜商品独特长尾词：单品搜不到=单品踩雷；全店搜不到=进小黑屋（冷处理 `3~5` 天 + 下架可疑品 + 真实买家消费，切忌一次性全删）。 |

## 四、明确「不用浪费精力」的 6 个伪目标（已证伪）

1. **不在全新品牌标品文案里编造“个人闲置 / 年会抽奖 / 朋友送”故事**：本库 `15,236` 条数据实证，含此类话术的商品仅 `164` 条（`1.1%`），且 **`≥100` 想要爆款率仅 `1.8%`**（中位想要 `2.0`，远低于大盘均值 `9.7%`）；写清**官方直发/品牌渠道、精确规格折合单价、新鲜批次**才是正向做法。
2. **不迷信“改 MD5 洗图工具”**：早已被视觉特征向量算法淘汰，完全无效。
3. **不花时间同步“圈子 / 鱼塘”或蹭无关热门话题**：流量多为同行互看水分，低停留与零想要反而拉低推荐模型转化分。
4. **不每天花 1–2 小时机械“刷首页点赞养号”**：只看不买的高频机械动作更像脚本；新号正常完善资料、授权芝麻信用、`2~3` 天内产生 `1~2` 笔真实买方消费足矣。
5. **不虚拟修改城市定位到北上广深**（非真实同城面交时）：系统校验网络 IP 与 GPS 一致性，冲突必招降权且易引跨城投诉。
6. **不在发品时硬填虚假/夸张 `originalPrice`（划线原价）或强凑无关 `cpv_labels`、也不用硬凑 9 张废图**：本库实证 `81.5%` 的商品未填更高原价；`cpv_labels` 填准 `1~2` 个核心属性即可；图数按日均效率以 `2~4` 张精选图最快。
