## 二、 核心文件路径与全站架构

### 1. 整体请求链路
* **用户浏览器 / 微信** ➔ **Nginx (80 / 443 端口)** ➔ **本地 Python 后端 (`127.0.0.1:8001`)** ➔ **本地 MongoDB (`127.0.0.1:27017`)** + **本地 Meilisearch (`127.0.0.1:7700`)**
* **Nginx 路由与防白屏缓存规则:**
  * **动态页面与接口 (`/`、`/detail`、`/group_help`、`/api/`):** 转发至本地 `8001` 端口，强制 `no-cache, no-store`，确保发版后新 HTML 秒级生效。
  * **静态资源 (`/static/`):** 转发至本地 `8001` 端口，协商缓存（`public, no-cache`），彻底避免“新 HTML 匹配旧 JS”引起的白屏崩溃。
  * **公用防爬虫与限流:** 全站统一维护在 **1 份 Nginx 配置** 中（公用 API 限流 `10r/s burst=30`、单 IP 最大 30 连接、拦截黑产扫描器与商业爬虫、放行微信与正常浏览器、隐藏 `/docs`、`/openapi.json` 及 `/api/system/upstream-health`）。

### Step 3：在服务器安装 Meilisearch 搜索服务（与本地完全一致，只需装这一次）

为了让资源有限的云服务器也能稳跑、且不用额外装臃肿的 Docker，推荐用 **方式 A：单文件免 Docker 部署**（内存限制 256MB，与本地 `localhost:7700` 和 `meilisearch_key` 完全一致）。若服务器上已有 Docker，也可以直接用方式 B。

#### 方式 A（推荐，省内存免装 Docker）：单二进制 + Systemd
```bash
mkdir -p /data/meili_data /opt/meilisearch
# 下载官方 v1.12 Linux 二进制（通过国内加速通道下载，极快）
curl -L https://ghfast.top/https://github.com/meilisearch/meilisearch/releases/download/v1.12.8/meilisearch-linux-amd64 -o /opt/meilisearch/meilisearch
chmod +x /opt/meilisearch/meilisearch

# 创建守护服务（注意 --master-key 与你 config.local.json 中的 meilisearch_key 保持完全一致，默认 easyshop2026）
cat > /etc/systemd/system/meilisearch.service << 'EOF'
[Unit]
Description=Meilisearch Search Engine
After=network.target

[Service]
Type=simple
ExecStart=/opt/meilisearch/meilisearch \
  --http-addr 127.0.0.1:7700 \
  --db-path /data/meili_data \
  --master-key easyshop2026 \
  --max-indexing-memory 256Mb \
  --no-analytics
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now meilisearch.service
systemctl status meilisearch.service --no-pager
```

#### 方式 B（备选，如果服务器本就装好了 Docker）
```bash
docker run -d --name meilisearch --restart always -p 127.0.0.1:7700:7700 -v /data/meili_data:/meili_data -e MEILI_NO_ANALYTICS=true -e MEILI_MASTER_KEY=easyshop2026 getmeili/meilisearch:v1.12
```

### Step 4：部署唯一的商城 Nginx 配置（只需做这一次，不碰主域名）

```bash
# 1. 创建 Certbot 验证目录
mkdir -p /var/www/html

# 2. 复制仓库内唯一生产 Nginx 配置（只配置 www.shop.easyeverything.cn 和 shop.easyeverything.cn）
cp /root/easy_shop_web/mobile_web/deploy/mobile_web.nginx.conf /etc/nginx/sites-available/shop.easyeverything.cn.conf

# 3. 停用自带的 default 站点，启用商城配置

ln -sf /etc/nginx/sites-available/shop.easyeverything.cn.conf /etc/nginx/sites-enabled/shop.easyeverything.cn.conf

# 4. 校验语法并立即生效
nginx -t && systemctl reload nginx
```

### Step 5：放行 `443` 端口并一键开启 HTTPS（只需做这一次，证书自动续期）

1. 先到腾讯云轻量控制台「防火墙」页面，确认已放行 **`TCP:443`**（`22` 和 `80` 保持放行；`8001` 和 `7700` 不要放行）。
2. 在服务器执行一条命令申请并自动配置免费 HTTPS 证书：
   ```bash
   apt-get update && apt-get install -y certbot python3-certbot-nginx
   certbot --nginx --non-interactive --agree-tos -m <你的邮箱> -d www.shop.easyeverything.cn -d shop.easyeverything.cn

   # 测试证书自动续期是否正常
   certbot renew --dry-run
   ```
3. **最后验收**：
   - 在微信或浏览器打开 **`https://www.shop.easyeverything.cn`**，确认页面正常、底部显示 `蜀ICP备2026073570号-1`、搜索「严选好价」毫秒级出结果、详情页和转链正常；
   - 访问 `https://www.shop.easyeverything.cn/docs` 应返回 `404`，访问 `http://124.220.169.204/` 应被拦截无响应。

## 五、 本地 MongoDB 数据库服务运维

| 配置项 | 路径或对应值 | 说明 |

| **日志文件路径** | `/var/log/mongodb/mongod.log` | 运行及报错排查日志 |
| **监听端口** | `27017` | 默认数据库端口（*提示：如本地需要直连同步，建议在腾讯云防火墙仅对常用 IP 放行，不要对 `0.0.0.0/0` 全开放*） |

| **用户密码** | `localPassword123` | 与 `config.local.json` 保持严格一致 |
| **默认业务库** | `crawler_data` | 商城商品详情、推荐流与订单数据存放库 |

```bash
systemctl status mongod

# 交互命令行直连

# 数据导出与恢复
```

## 七、 从零部署全新空白服务器极简 SOP（备份交接用）

若未来换到一台全新空白 Debian 服务器，按以下 6 步即可从零部署完整上线：
1. 装系统软件：`apt-get update && apt-get install -y git curl gnupg ca-certificates python3 python3-venv nginx certbot python3-certbot-nginx`
2. 装 MongoDB 8.0，建立 `localUser` 用户与开启 `authorization: enabled`。
3. 克隆仓库并建虚拟环境：
   `cd /root && git clone https://ghfast.top/https://github.com/differentname123/easy_shop_web.git && cd easy_shop_web/mobile_web && python3 -m venv .venv && .venv/bin/python -m pip install -r requirements.txt -i https://mirrors.cloud.tencent.com/pypi/simple`

5. 按第三章 Step 3 安装 Meilisearch 并执行 `sync_meilisearch.py`。
6. 配置 `/etc/systemd/system/mobile_web.service` 开机自启，再按第三章 Step 4、Step 5 配好唯一 Nginx 与 Certbot HTTPS。

## 八、 常见故障排查 (避坑经验汇总)

### 🚨 故障 1：访问报 `502 Bad Gateway`
* **原因：** 后端未启动、拉代码后漏装新依赖包（如 `meilisearch`、`cv2`），或 Nginx 端口与 `config.local.json` 的 `web_port`（`8001`）不一致。
* **解决：**
  1. `journalctl -u mobile_web.service -n 50 --no-pager` 看真实报错；
  2. 补跑安装依赖并重启：`/root/easy_shop_web/mobile_web/.venv/bin/python -m pip install -i https://mirrors.cloud.tencent.com/pypi/simple -r /root/easy_shop_web/mobile_web/requirements.txt && systemctl restart mobile_web.service`；
  3. 确认 `systemctl status mobile_web.service` 为 `active (running)`。

### 🚨 故障 2：访问商品详情页或首页出现全白屏
* **原因：** 浏览器强缓存了旧 JS，配了新版 HTML。
* **解决：** 确保使用本仓库最新 [mobile_web.nginx.conf](mobile_web/deploy/mobile_web.nginx.conf)（已给 `/static/` 配 `public, no-cache`、`/` 配 `no-cache, no-store`），客户端清缓存或 `Ctrl+F5` 即可。

### 🚨 故障 3：`nginx -t` 报错 `duplicate default server` 或 `duplicate "server_tokens"`
* **原因：** 忘记删旧软链 `/etc/nginx/sites-enabled/default`。
* **解决：** 执行 `rm -f /etc/nginx/sites-enabled/default && nginx -t && systemctl reload nginx`。

### 🚨 故障 4：国内服务器 `git pull` 或 `curl` 下载卡死
* **原因：** 直连 GitHub 超时。
* **解决：** `git config --global http.sslVerify false`，下载与拉取时加加速前缀 `https://ghfast.top/https://github.com/...`。

### 🚨 故障 5：严选好价搜索报 Meilisearch 连接异常
* **原因：** Meilisearch 未启动，或 `config.local.json` 中 `meilisearch_key` 与 `meilisearch.service` 里的 `--master-key` 不一致。
* **解决：** 执行 `curl -s http://127.0.0.1:7700/health` 检查存活，核对密钥一致后重启 `meilisearch.service`（注：就算 Meilisearch 临时停止，前端也会 10 秒自动降级回 MongoDB，绝不白屏）。

### 🚨 故障 6：后端启动报 `localhost:27017: Connection refused` 或 `Authentication failed`
* **解决：** 执行 `systemctl status mongod` 检查服务存活，再用 `/root/easy_shop_web/mobile_web/.venv/bin/python /root/easy_shop_web/mobile_web/run.py --check-mongo` 自检确认密码与配置一致。
